# Consumed Sankey source symbols

Internal source ownership architecture following `a4f933d9af2cd3ccd5cda7eac46dc1048a296249`. It changes no public API, wire format, JavaScript algorithm or admission authority.

`Reader::take/field` borrow the prepared source. `name` trims exactly as before and returns `Cow::Owned` only when doubled quotes require the existing replacement. `amount` consumes the same borrowed field. One generic grammar resolves completed rows through `Target::node`; its legacy target retains `SankeyModel`, first-mention lookup and owning endpoint clones. No grammar/token/error-coordinate changes.

Source target is `SourceSymbols`: a single `HashMap<String, Symbol>` owns unique text. Each symbol has a `usize` catalog ID, UTF16-unit count and optional node ordinal. New source nodes allocate their label symbol then intern `id`/`index`; a static symbol first becoming a node receives the next node ordinal, never its catalog ID. After grammar END, finish appends decimal keys, link keys, root keys/title in the prior SourceCanonical order. Consuming map keys into their recorded slots preserves IDs independently of HashMap iteration. There is no persistent reverse map or borrowed reference into temporary parser input.

`IndexedSankey` owns this final catalog, node label IDs, decimal/key IDs, links and optional title ID. `SourceCanonical` shares it through the existing Arc and keeps only mutable overlays, extent/root and receipt state. `Input::NodeView` lends labels to the unchanged renderer/layout and generic canonical builder. Public DTO fields, serde/downcasts, explicit arbitrary DTO indexes/detached endpoint matching, provider provenance and partial helper refresh stay unchanged.

Removed source-path copies: owned lexical field for each endpoint/amount; unconditional normalized-name allocation for ordinary labels; cloning each first label into IndexedSankey.nodes; recreating/cloning unique label/title/static/decimal keys into SourceCanonical's temporary second interner. Required first unique owned text, escaped-name normalization, decimal formatting, source UTF16 encoding, native validation, wire bytes and real JS public objects remain. Catalog lengths/IDs use usize until canonical atom/column conversion; existing post-grammar initial admission still rejects invalid extents/limits before exposure. No newly minted proof or earlier semantic limit. The latent ordered 2×UTF8-node-label text budget remains after initial admission.

Original catalog is immutable through adopted UTF16 replacements (including lone surrogates), history truncation/reset and sparse overrides. Full03/update01/full01 fallback fields and f64 to_bits paths remain the same. Shape/number/control flow in render is unchanged; only borrowed node access replaces its owning slice interface.

Seven files: six Sankey runtime files and existing public source-owned integration. Two added vectors cover all static-name/decimal/title collisions and repeated whitespace/doubled-quote normalized labels. Existing 11,616-source frozen graph/error corpus, first-helper-without-export, arbitrary provider, raw/edit/partial failure, original catalog reset and exact budget tests remain execution gates. No unit tests.

Verification requires the frozen source graph/error corpus, native public lifecycle and provider integrations, browser oracle comparisons, and fresh Swift/C consumers built from these inputs. Performance and allocation claims require matched measurement. Final catalog transfer uses temporary Option slots for ordered safe moves; it introduces no unsafe or uninitialized memory and changes no hashing policy.
