# Private owned public construction pilot

Five-file patch. Production untouched; no compilation, test execution or measurements.

The paired public codec consumes its captured parsed document after the existing schema-view validation. An opaque carrier retains concrete parser provenance and prepared/edge policy. Default providers dispatch the exact previous borrowed hooks; original core registration and config remain alive during the callback. Existing typed adaptation/raw/apply/invoke paths stay unchanged.

Only Sankey opts in, only for its concrete parser and ordinary source. Its graph construction is unchanged. The original typed model is moved into retained state after equivalent text-expansion admission; endpoint labels are dropped to match the imported projection. Arbitrary same-model providers cannot obtain this optimization by delegating to Sankey: the private creator TypeId survives delegation. Prepared parsing deliberately retains the legacy branch.

`LLD.md` records cross-family scope, normalization proof, explicit exclusions and measurement gates. `manifest.json` binds original/candidate hashes; `candidate.patch` applies against the current source originals. Public integration covers the full 11,616-source graph/error corpus, first render/edits/helper, replacement, malicious delegation, default callback dispatch, and source/prepared policy. Tests remain unexecuted.

Acceptance needs native integration, allocation/peak and current-profile evidence, then actual browser/Swift package first-use checks. The source-predictable avoided Sankey reconstruction allocations are a mechanism hypothesis, not a measured latency result. No blanket rollout to the other 25 eager projection codecs is proposed.
