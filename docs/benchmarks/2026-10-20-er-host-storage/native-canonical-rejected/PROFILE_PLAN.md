Original pre-run plan; the authorized execution is recorded in RUN.md and PROVENANCE.json. Same complete immutable control/candidate package bytes are mandatory. Control disables the internal backend switch before renderer creation; candidate enables it. Both packages must expose the storage probe. Exact SVG and dimension checks surround each pair of sampling windows.

Default bounded run: Sankey medium, fixed measurer, one 2-second window per parse/retained/source stage and runtime (six profiles), 300ms warmup, 250us sampling. Source render is the negative control. Runtime run loop and CDP start/stop sequence are byte-identical to the corrected captured profiler. No forced GC, wrappers or production instrumentation. Raw profiles are written before their weighted summary; package hashes are rechecked after completion.
