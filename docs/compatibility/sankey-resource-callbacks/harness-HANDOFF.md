## Integration/run (parent only)

Apply candidate.patch at repo root. Then, against its already-built default package:

```sh
node scripts/verify-sankey-resource-callbacks.mjs dist/package-web/package dist/evidence/sankey-resource-callbacks-node.json
npx playwright test tests/web/sankey-resource-callbacks.spec.js
```

Node hashes every candidate package file before/after, checks the actual oracle bundle, and always closes the renderer. Browser records oracle/full.js/WASM/scenario hashes before/after each group and closes the renderer; Playwright owns page/browser cleanup. Its route serves only the shared TEST scenario module under the existing server allowlist. No package module is intercepted, replaced, or instrumented.

This harness deliberately does not weaken existing restoration tests. Parent must decide which prior rollback assertions conflict with the newly demonstrated oracle contract and revise those separately with explicit evidence. Functions in descriptor snapshots are represented by arity; this proves object/collection alias and descriptor parity, not universal function-object identity. This feature does not establish universal Proxy/getter/intrinsics parity or disposal-during-render behavior. No output-limit, giant allocation, or performance cases were added.
